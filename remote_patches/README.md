# Historical remote patches

These files record earlier proxy-server and structured-output experiments
against historical AReaL revisions. They are not part of the current
production Level-1 launch path.

- Top-level `.patch` and `.diff` files are retained patch variants.
- `archive/work/` contains before/after source snapshots used to build and
  inspect those variants.

For the current dynamic open-action-mask training patch, use
[`../patches/areal_pacman_action_logprobs.patch`](../patches/areal_pacman_action_logprobs.patch).
